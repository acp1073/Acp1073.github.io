# 多级分类与文章归档

分类属性使用 `/` 表示层级。例如：

```yaml
category: 图形学/games202
```

博客归档页会默认显示可折叠的分类树：

```text
图形学
├─ GAMES101
│  └─ 材质
└─ GAMES202
   ├─ 阴影
   └─ Real-time Environment Mapping
```

最后一层是可打开的文章。分类支持更多层级，例如 `图形学/games202/软阴影`；在上级分类直接发表的文章也会显示在该分类中。

侧栏分类可以展开、折叠，并显示包含子分类的文章总数。点击父分类会显示它和所有子分类的文章，点击子分类会限定到该路径。文章日期旁的分类显示为可点击的层级导航。归档页的“按时间”按钮可以切换到原有的年份列表。

单层分类仍可直接使用，例如 `category: 生活`。没有分类的文章放在“未分类”。分类名称不会随界面语言自动翻译；GAMES101/GAMES202 的显示统一为大写，实际分类路径使用保存的名称。

个人 Obsidian 导出工具会把笔记所在的完整文件夹层级写入分类，例如：

- `图形学/games101/材质.md` → `图形学/games101`
- `图形学/games202/阴影.md` → `图形学/games202`
- `生活/旅行/游记.md` → `生活/旅行`

手动填写的 `category` 优先于文件夹规则。文章在博客仓库中的文件夹可以继续使用 `src/content/posts/material/`；归档根据分类属性生成，不要求博客源码目录复制整套笔记库结构。

本地开发预览会显示草稿。正式构建只会把已发布文章计入分类和归档；新增分类会在第一篇对应文章发布后出现在网站中。
